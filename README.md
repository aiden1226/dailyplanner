# Daily Planner

A free, private dashboard for your day. Start with a calm breathing intro, then manage tasks, a calendar, a journal, habits, goals, lists, and a focus timer, all in one black-and-gray page.

There is no account, no server, and no build step. The whole app is a single `index.html` file, and everything you enter is saved in your own browser.

## Features

**Title/Beginning**
- Calm intro screen with a breathing animation before you enter
- Greeting that changes with the time of day, a live clock, and the date in your own time zone
- A new quote every day
- "Today at a glance" summary: tasks done, what's next, journal entries, and latest mood

**Plan**
- **To-dos** with an optional time, priority, and category, daily or weekly repeats, and a category filter
- **Calendar** with a month view, events with optional times, and weekly or monthly repeats
- **Countdowns** showing days left until a trip, deadline, or event

**Reflect**
- **Journal** you can write in at any time of day, with optional mood tags, search, and a 7-day mood strip
- **Daily review** prompts (what went well, plan for tomorrow) that save to your journal
- **Quick notes** scratchpad that saves as you type

**Build routines**
- **Habits** with daily check-ins and streaks
- **Goals** with a target and progress bar
- **Focus timer** with 25, 15, and 5 minute presets
- **Grocery list** and a general **checklist**

**Make it yours**
- Gray, Charcoal, and Light themes
- Your name for the greeting, a 24-hour clock option, and a Monday week start
- Export and import backup
